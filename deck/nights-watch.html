Live demo

  • Night's Watch Inc. uses five vendors: AWS, Nimble, Tinybird, Liquid AI, Black Forest Labs.
  • Its rules: R1 approved countries only. R2 no AI training on customer data. R3 retention of 90 days or less.
  • We make three changes to the Tinybird demo mirror and run a tick after each.
  • A date edit is dropped. The other two turn the node red.

How it works

  • Nimble reads each vendor's sub-processor list and privacy policy.
  • Unchanged pages and date-only edits are dropped before any model call.
  • Liquid LFM2.5 judges each new policy sentence. A second model reviews the few that would change a verdict.
  • The agent starts from its state card, rewrites it, and pulls older history from RawTree only when it needs it.

A year, simulated

  • Six vendors, 365 days, five planted rule breaks. 5 of 5 caught, no false alerts.
  • Context for all six state cards: 1,542 to 1,811 tokens.
  • An agent that keeps the full history needs 428,956 tokens on day 365. It passes Liquid's window on day 56.
  • 8 crashes injected over 60 days. Memory came back identical.
